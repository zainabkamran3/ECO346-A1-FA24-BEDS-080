1. Introduction

This project examines education spending and literacy patterns among households and individuals in rural Punjab using PSLM data. The analysis focuses on the distribution of education expenditure and differences in literacy rates between males and females across age groups.

The visualizations were prepared in R, with a separate Python analysis used to check whether the literacy results can be reproduced.
